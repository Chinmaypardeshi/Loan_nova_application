# LoanNova Flutter UI MVP

This is a frontend-only Flutter MVP for LoanNova.

## Run

```bash
flutter pub get
flutter run
```

No external packages are required.

## Current UI

- Animated fintech hero section
- Home dashboard
- Loan categories
- Recommended loan card
- Credit score card
- Quick tools
- Bottom navigation
- Placeholder screens for Loans, Compare, Applications and Profile

Backend/API integration can be added later without changing the overall UI structure.
